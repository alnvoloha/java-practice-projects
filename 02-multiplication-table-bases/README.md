# Multiplication Table in Different Bases

Prints a multiplication table (1..10) in base 2 / 8 / 10 / 16 based on user choice.

## Highlights
- Interactive choice of numeral system (2, 8, 10, 16)
- Formats each multiplication result using Java built-ins (`toBinaryString`, etc.)
- Demonstrates control flow and output formatting

## How to run
Run `volohaLab113` or `volohaLab213` (plain Java).

## Notes
- Build artifacts (`target/`, `out/`, `*.class`) are intentionally excluded from version control.
- If the project reads input from a file, the default dataset is located in `src/main/resources/`.
