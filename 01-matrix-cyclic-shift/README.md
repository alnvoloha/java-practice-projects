# Matrix Cyclic Shift

A small CLI tool that performs cyclic shifts on a matrix and prints the result.

## Highlights
- Reads matrix size and shift parameters from stdin
- Implements a cyclic shift operation (wrap-around)
- Focuses on clean iteration logic and boundary handling

## How to run
Run the `Main` class from your IDE (plain Java project).

## Notes
- Build artifacts (`target/`, `out/`, `*.class`) are intentionally excluded from version control.
- If the project reads input from a file, the default dataset is located in `src/main/resources/`.
