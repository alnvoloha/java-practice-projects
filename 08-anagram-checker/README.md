# Anagram Checker

Checks whether two strings are anagrams with normalization and clean CLI UX.

## Highlights
- Normalization (case, whitespace)
- String/character processing
- Clear, minimal CLI interface

## How to run
Run `main.Main` (Maven project).

## Notes
- Build artifacts (`target/`, `out/`, `*.class`) are intentionally excluded from version control.
- If the project reads input from a file, the default dataset is located in `src/main/resources/`.
