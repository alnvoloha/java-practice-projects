# Text Formatter + Spiral Cipher

Two text tasks in one tool: letter-to-index formatting and a square-table spiral cipher.

## Highlights
- Letter-to-index formatting with aligned two-line output
- Square-table transform: rotate, swap rows/cols, spiral readout
- String-based implementation + Stream API variant
- Regex usage and defensive validation

## How to run
Run `run.Main`. Input text is read from `src/main/resources/text.txt`.

## Notes
- Build artifacts (`target/`, `out/`, `*.class`) are intentionally excluded from version control.
- If the project reads input from a file, the default dataset is located in `src/main/resources/`.
